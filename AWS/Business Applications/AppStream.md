Amazon AppStream 2.0 is a fully managed service that allows you to stream desktop applications to users from AWS, without the need to rewrite or repackage them. It provides a secure and scalable way to deliver Windows applications to any device through a browser, enabling access from anywhere. AppStream 2.0 integrates with your existing identity, storage, and network resources, and supports automatic scaling based on user demand. It is ideal for use cases such as remote work, software trials, training, or running resource-intensive applications without requiring powerful local machines.

Documentation: [AppStream Reference](https://aws.amazon.com/appstream2/)

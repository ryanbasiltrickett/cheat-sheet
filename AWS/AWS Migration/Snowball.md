AWS Snowball is a physical data transport and edge computing device designed to help organizations move large volumes of data—ranging from terabytes to petabytes—to and from AWS efficiently and securely. These devices not only support high-speed, secure data transfer using built-in encryption but also offer local compute capabilities for running applications at the edge using services like AWS Lambda and EC2 instances. Snowball is ideal for use cases with limited or no internet connectivity, such as remote sites, data center shutdowns, or large-scale data migrations. Once data is loaded onto the device, it is shipped back to AWS, where the data is automatically imported into services like Amazon S3.

Documentation: [Snowball Reference](https://docs.aws.amazon.com/snowball/latest/developer-guide/whatisedge.html)

AWS IoT Things Graph is a service that lets you visually model and build IoT applications by connecting different devices and web services into workflows. It uses a drag-and-drop interface to define how devices and services interact, making it easier to create complex IoT solutions without writing extensive code. Each device or service is represented as a reusable component with defined inputs, outputs, and actions. IoT Things Graph supports common protocols and integrates with AWS [[IoT Core]] and other AWS services, enabling faster development of applications like smart home automation, industrial monitoring, and asset tracking.

Documentation: [IoT Things Graph Reference](https://aws.amazon.com/blogs/aws/now-available-aws-iot-things-graph/)

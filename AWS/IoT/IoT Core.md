AWS IoT Core is a managed cloud service that enables devices to connect securely and interact with cloud applications and other devices. It supports millions of devices and billions of messages, allowing you to process and route data with low latency and high reliability. IoT Core supports communication using MQTT, HTTP, and WebSockets, and integrates with other AWS services for analytics, storage, and machine learning. It also includes built-in authentication and authorization to ensure secure device communication, making it ideal for building scalable and secure IoT applications across industries like manufacturing, healthcare, and smart homes.

Documentation: [IoT Core Reference](https://aws.amazon.com/iot-core/)

### Overview
#### Features
- Ingest IoT Messages
- Publish Messages to IoT Devices
- Enable Connection to and from AWS Services
- Rules based Message Routing

AWS IoT Analytics is a fully managed service that enables advanced analysis of data collected from IoT devices. It automates the steps required to clean, filter, transform, and enrich raw IoT data before storing it for analysis. You can run custom queries, perform statistical analysis, and build machine learning models using integrated tools like Jupyter Notebooks and Amazon [[SageMaker]]. IoT Analytics helps you uncover insights, detect patterns, and make data-driven decisions for use cases like predictive maintenance, device performance optimization, and operational monitoring, all without managing complex infrastructure.

Documentation: [IoT Analytics Reference](https://aws.amazon.com/iot-analytics/)
